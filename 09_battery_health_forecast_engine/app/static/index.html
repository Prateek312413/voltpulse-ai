Deterministic Selection Hierarchy (PRD Standard):

  1. Valid Execution: Candidate must complete Cholesky factorization and fitting without decomposition failure.
  2. Validation RMSE: Lower root-mean-squared error on chronological holdout set (tolerance: 1e-6).
  3. Interval Coverage Calibration: Empirical coverage closest to target (95% CI).
  4. Validation MAE: Lower mean absolute error.
  5. Deterministic Kernel Tie-Break: Stable alphabetical order (Matern32 < Matern52 < RBF < RationalQuadratic).
